# 打印常见问题：从"没反应"到"双面没生效"

收集了业务系统在接入打印时最常遇到的一批问题，按荔枝打印助手的实际行为给出答案。如果你正在排查线上打印故障，建议从第一条开始顺着看。

## 一、任务提交了，打印机没反应

先按这个顺序排查：

1. **打印机是否设置好**：确认目标打印机存在、不是脱机状态、有纸。客户端打印时优先使用任务里指定的打印机；没指定就用配置里的默认打印机；两者都没有则用系统默认打印机。
2. **驱动是否就绪**：打印机驱动由管理员通过厂商官方渠道安装。客户端不自动下载、不自动安装任何驱动，只提供只读的自检命令查看本机打印机、驱动名与可用性。
3. **任务是否进了队列**：打开打印队列页看状态。失败的任务会显示原因，可以单独重试；等待中的任务说明还在排队。
4. **容不容易被忽略的一点**：如果主窗口是隐藏的，新任务入队时客户端会自动弹出队列页并给一个气泡提示——留意这个提示能第一时间看到失败原因。

## 二、提示"打印机无效"或操作失败

这类提示基本都指向打印机名称对不上。请确认任务里传的打印机名和系统里的名称**完全一致**，包括空格和大小写。可以用获取打印机列表的命令拿到准确名称，再原样传回。

如果任务里根本没传打印机，检查配置里的默认打印机是否填了一个已经不存在的名字。把默认值清空，让它回退到系统默认打印机即可。

## 三、打印位置有偏移

位置偏移通常不是客户端的问题，而是纸张和边距没对齐：

- 先确认驱动里设置的纸张与你要打印的纸张一致。客户端的纸张参数会下发给驱动，但**最终纸张由驱动和打印机决定**。
- 再确认页边距。边距的单位是一英寸的百分之一，50 约等于 12.7 毫米。偏得多时先归零再逐步调。
- 如果是套打单据，底图和数据必须在同一个文件（或同一份模板）里定位，否则两边各自对齐会累积误差。

## 四、双面打印没生效

双面参数会同时下发给文档输出和系统打印设置，但**能否真正双面取决于打印机和驱动是否支持这个能力**。不支持双面的打印机收到这个参数也不会报错，只是按单面打。

另外注意取值的写法：单面、长边翻转、短边翻转是三个不同的值，别只写一个"双面"就以为够——请用参数表里约定的取值。

## 五、为什么传了边距，PDF 没变化

这是最常见的误解之一。PDF 的页面尺寸由文件自身和缩放方式决定，边距主要作用于客户端直接排版绘制的类型（图片、文本、SVG、条码）以及输出成 XPS 的场景。要改变 PDF 的留白，应该在生成 PDF 时就控制好页面内容和尺寸。

## 六、背景图、水印、印章打不出来

它们属于**内容**而不是打印参数。请把它们放进文件本身或 HTML 模板里。HTML 转成 PDF 时，用 CSS 的打印颜色保留设置让背景图形一起输出；客户端没有单独的"打印背景"开关。

## 七、条码或二维码扫不出来

优先检查清晰度而不是尺寸参数：

- 用图片或 PDF 承载码，保证足够分辨率，别用屏幕截图这种低清来源。
- 二维码物理尺寸不能太小，普通打印机上过小的码容易糊成一团。
- 一维码的条与空要有足够对比，避免浅灰、反白等低对比搭配。
- 换行、空格、不可见字符会被编进码里，提交前先核对码值本身。

## 八、网络链接打印失败

先确认这个链接客户端能直接下载。客户端下载用标准的 GET，不转发自定义请求头；如果链接需要登录态或带鉴权头，请在业务系统侧生成一个可直接下载的地址再提交。

类型识别按"文件名后缀 → 文件字节特征 → 响应内容类型"的顺序进行，三者都识别不出来会直接报错，不会猜一个格式硬打。所以给网络文件一个明确的后缀，能省掉很多排查时间。

## 九、内联内容一定要给文件名吗

看内容本身：

- 如果内容带可识别的特征（例如 PDF、PNG、JPEG 的文件头，或 HTML、SVG 的标记），或者用了带媒体类型的数据地址，不必额外给文件名。
- 否则必须提供带扩展名的文件名。识别不出又没给文件名，会直接返回错误，不会猜测。

纯文本内容按文本这个"编码事实"处理，不需要特别声明类型。

## 十、版本对不上，某能力为什么没有

三件事要分开看：

- **源码版本**：代码库里的最新版本，包含刚开发完的能力。
- **线上发布版本**：官网可下载的安装包版本，只有打了发布包的能力才在这里。
- **本机版本**：你当前电脑上实际运行的版本，用健康检查接口可以查看。

文档描述的是源码具备的能力。如果文档里写了某个能力，但你下载的安装包里没有，通常是因为那个能力还没打进新的发布包。请对照版本对照表确认。

## 十一、能远程打印吗

可以，需要在设置里显式开启主动在线打印并配置中继地址。开启后本终端主动连接中继服务器，接受远程任务；命令走白名单，只允许已配置的命令。这是一项可选能力，默认关闭。

## 十二、安全边界怎么把握

客户端内嵌的本机服务不提供访问鉴权，应当只在本机或受控内网使用。如果需要开放到局域网或公网，请自行配置网络隔离与防火墙策略。

打印机驱动请走厂商官方渠道；客户端只做只读自检，不自动下载或安装任何驱动。

## 小结

打印问题的绝大多数都能归到四类：**打印机与驱动、纸张与版式、内容与类型、版本与配置**。按这个顺序排查，比逐个参数试错要快得多。

需要完整的参数含义和生效范围，请看开发者文档里的"打印参数与默认值"；需要对接接口，从"快速开始"入手。
