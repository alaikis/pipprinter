PipPrinter 小莱打印助手

常驻 Windows 系统托盘的本地打印助手：对外提供 WebSocket 指令通道与 REST API，对内提供打印队列、本机打印机管理、磁盘清理与多格式文件打印。

这是一份随应用一起运行的本地文档。 本页由应用内嵌的 ASP.NET Core (Kestrel) 服务托管， 地址 http://127.0.0.1:19861；端口可在「设置」页修改。所有接口默认只监听本机（WebSocket 默认监听 0.0.0.0 以便局域网调用）。

快速开始

  1. 启动 PipPrinter.exe。程序不会弹出主窗口，而是在系统托盘出现图标，并弹出气泡提示。
  2. 双击托盘图标即可显示主窗口（默认打开「打印队列」页）；最小化或关闭主窗口会收回托盘，只有菜单中的「退出」才真正结束进程。
  3. 右键托盘图标：打开主窗口、快速打印、查看队列、打印机列表、磁盘清理、打开本文档、设置、退出共 8 项。
  4. 切换到「打印」页，选择文件或填写 URL，指定打印机与份数，点击 立即打印 或 加入队列。
  5. 外部系统可通过 WebSocket 或 REST 下发打印指令。

功能一览

托盘右键 UI/UX

8 项上下文菜单，双击托盘图标显示主窗口；主窗体 6 个 Tab 页面：打印、打印队列（默认）、打印机、磁盘清理、设置、日志。

打印队列

顺序消费、失败重试、取消/删除、崩溃恢复；队列持久化到 data/queue.json，并通过 WebSocket 主动推送变更。

本机打印机列表

枚举已安装打印机，展示驱动、端口、纸张规格；一键设为默认、打印测试页。

磁盘清理

扫描临时目录与大文件，白名单保护、试运行、回收站删除、清单导出；默认 dry-run。

多类型文件打印

PDF 走 SumatraPDF；Office/图片/文本走系统关联程序；HTML 走无头浏览器转 PDF；支持 URL 直接打印。

内嵌 Web 服务

Kestrel 静态文档站 + REST 端点；/api/status 可查询运行时状态与队列摘要。

支持的文件类型

.pdf.doc.docx .xls.xlsx.ppt .pptx.rtf.odt .png.jpg.jpeg .bmp.gif.tif.tiff .html.htm.mhtml .txt.csv.log.md

未知扩展名会交给系统 Shell 的 print 动词兜底；若系统没有可打印该类型的应用，需在客户端手动打开。
