Kestrel / ASP.NET Core 10 · 端口 19861

REST API

内嵌 Kestrel 服务，默认 http://127.0.0.1:19861。已启用 CORS，静态文档站与 API 共用同一端口。所有 API 与 WebSocket 命令 共用 CommandDispatcher，响应结构完全一致。

GET/health轻量探活：status/app/version/uptimeSeconds/web/ws/wsConnections/aoOnline/queue，供负载均衡与监控秒级判断

通用命令入口

curl -X POST http://127.0.0.1:19861/api/command \
  -H "Content-Type: application/json" \
  -d '{"cmd":"GetPrinterDetail"}'

# 等价于
curl http://127.0.0.1:19861/api/printers

body 必须是 JSON 对象且包含 cmd；不在 allowedCommands 白名单里的命令返回 403。

幂等 / 批次 / 排期：QueuePrint 支持 idempotencyKey（同键未完成任务不重复入队，返回 deduped:true，防重复出纸与重复计费）、groupId+groupOrder（同批按序消费）、dueAt（到点才打印）。dueAt 支持 ISO8601 带时区、Unix 秒与本地时间字符串，内部统一按本地时间调度。

排期 · 批次 · 召回 · 推荐

# 1) 排一个计划任务：到点自动入队打印（本地持久化，重启不丢）
curl -X POST http://127.0.0.1:19861/api/schedule \
  -H "Content-Type: application/json" \
  -d '{"dueAt":"2026-11-20T14:30:00+08:00","target":"C:\\orders\\batch1.pdf","printer":"HP LaserJet","copies":2,"note":"午后波次"}'
# → {"code":200,"data":{"planId":"...","dueAt":"...","job":{...}}}

# 2) 查看 / 撤回计划（提前触发带 now:true）
curl http://127.0.0.1:19861/api/schedule
curl -X DELETE http://127.0.0.1:19861/api/schedule -H "Content-Type: application/json" -d '{"planId":"..."}'
curl -X DELETE http://127.0.0.1:19861/api/schedule -H "Content-Type: application/json" -d '{"planId":"...","now":true}'

# 3) 批量/波次：整批同组按序入队，复用幂等与断网补打
curl -X POST http://127.0.0.1:19861/api/batch \
  -H "Content-Type: application/json" \
  -d '{"jobs":[{"target":"C:\\o\\1.pdf"},{"target":"C:\\o\\2.pdf"}],"idempotencyKey":"wave-001"}'
# → {"code":200,"data":{"groupId":"batch:...","count":2,"deduped":0,"jobIds":[...]}}

# 4) 智能推荐错峰时段（基于近 14 天真实审计流水，无历史则默认策略）
curl -X POST http://127.0.0.1:19861/api/recommend \
  -H "Content-Type: application/json" -d '{"count":5,"withinHours":8}'
# → {"code":200,"data":{"basedOn":"history","slots":[{"at":"...","hourLoad":2,"recommended":true},...]}}

# 5) 召回撤回未开始打印的任务（记审计；printing 出纸后不可撤）
curl -X POST http://127.0.0.1:19861/api/recall \
  -H "Content-Type: application/json" -d '{"id":"","reason":"客户取消"}'

# 6) 安全打印：提交时挂起，到打印机前用 PIN 释放
curl -X POST http://127.0.0.1:19861/api/print \
  -H "Content-Type: application/json" \
  -d '{"path":"C:\\secret\\合同.pdf","pin":"1234","releaseRequired":true}'
curl http://127.0.0.1:19861/api/jobs/held
curl -X POST http://127.0.0.1:19861/api/release \
  -H "Content-Type: application/json" -d '{"jobId":"","pin":"1234","releasedBy":"工卡 A001"}'

# 7) 配额与费用：设置月度限额，查询用量与流水
curl -X POST http://127.0.0.1:19861/api/quota \
  -H "Content-Type: application/json" -d '{"userId":"sales","monthlyLimit":2000,"colorLimit":300}'
curl 'http://127.0.0.1:19861/api/quota?userId=sales'
curl 'http://127.0.0.1:19861/api/cost/report?userId=sales'

# 8) 报表聚合（按打印机/用户/时段/色彩/引擎）
curl 'http://127.0.0.1:19861/api/report?groupBy=printer'

# 9) 打印策略：工作时段禁止彩色、强制双面
curl -X POST http://127.0.0.1:19861/api/policy \
  -H "Content-Type: application/json" \
  -d '{"name":"工作日黑白双面","startHour":9,"endHour":18,"denyColor":true,"forceDuplex":true,"maxCopies":5}'

# 10) 存档重放 / 预览 / 墨量 / 扫描收件箱
curl 'http://127.0.0.1:19861/api/archive?jobId='
curl -X POST http://127.0.0.1:19861/api/preview \
  -H "Content-Type: application/json" -d '{"path":"C:\\a.pdf","maxPages":3}'
curl 'http://127.0.0.1:19861/api/toner?host=192.168.1.50'
curl 'http://127.0.0.1:19861/api/inbox'
curl -X POST http://127.0.0.1:19861/api/inbox/print \
  -H "Content-Type: application/json" -d '{"name":"scan-001.pdf"}'

提交打印任务

curl -X POST http://127.0.0.1:19861/api/print \
  -H "Content-Type: application/json" \
  -d '{"path":"C:\\labels\\a.pdf","printer":"HP LaserJet","copies":2}'

# 响应
{
  "code": 200,
  "data": { "jobId": "3f9a...", "job": { "status": "pending", ... } },
  "error": "已加入打印队列",
  "operator": "QueuePrint",
  "uuid": "...",
  "timestamp": "1763019000"

path 也可以是 http(s) URL；printer 留空则使用系统默认打印机。

条码 / 二维码

curl -X POST http://127.0.0.1:19861/api/barcode \
  -H "Content-Type: application/json" \
  -d '{"value":"SO-20261113-001","format":"code128","caption":"订单号","printer":"HP LaserJet"}'

支持 qr、code128、code39、code93、ean13、ean8、upca、itf、codabar、msi、pdf417、datamatrix、aztec；width/height 默认 400px，caption 为可选文字。PNG 经 SumatraPDF 直出，不依赖系统看图软件。

打印到文件（PDF / XPS 虚拟输出）

# 打印到 PDF
curl -X POST http://127.0.0.1:19861/api/print/topdf \
  -H "Content-Type: application/json" \
  -d '{"path":"C:\\docs\\a.xlsx","output":"C:\\out\\a.pdf"}'

# 打印到 XPS（图片/文本用内置写入器，无需可选功能）
curl -X POST http://127.0.0.1:19861/api/print/toxps \
  -H "Content-Type: application/json" \
  -d '{"path":"C:\\docs\\a.txt","output":"C:\\out\\a.xps"}'

output 缺省时落到应用 temp/ 目录并返回绝对路径。PDF 走 Microsoft Print to PDF 虚拟打印机；XPS 对图片/文本使用内置 WPF 写入器（不依赖系统是否安装 XPS Document Writer），其余类型回退虚拟打印机。

ESC/POS 热敏小票

curl -X POST http://127.0.0.1:19861/api/escpos \
  -H "Content-Type: application/json" \
  -d "{\"printer\":\"192.168.1.100:9100\",\"text\":\"欢迎光临\\n合计：¥88.00\",\"barcode\":\"20261113001\",\"barcodeFormat\":\"code128\",\"cut\":true}"

printer 支持本地打印机名（Win32 RAW）或 host:port（TCP 9100 网络打印机）。encoding 默认 GB2312（自动注册代码页提供程序，中文不乱码）；可选 align、bold、qrcode、cashDrawer、feed、cut/cutMode。返回 bytes 与字节流 dump 文件路径。

扫描与清理

curl -X POST http://127.0.0.1:19861/api/command \
  -H "Content-Type: application/json" \
  -d '{"cmd":"ScanDisk","maxAgeDays":7,"minSizeMB":1}'

# 拿到 items[].Path 后，先试运行
curl -X POST http://127.0.0.1:19861/api/command \
  -H "Content-Type: application/json" \
  -d '{"cmd":"CleanDisk","paths":["C:\\...\\temp\\old.tmp"],"dryRun":true}'

# 确认无误再真正删除
curl -X POST http://127.0.0.1:19861/api/command \
  -H "Content-Type: application/json" \
  -d '{"cmd":"CleanDisk","paths":["C:\\...\\temp\\old.tmp"],"dryRun":false,"useRecycleBin":true}'
安全约束： CleanDisk 默认 dryRun=true；只有显式 false 才删除。 服务端会二次校验路径必须位于允许根目录（系统 Temp、应用 temp/ 与 log/）且不在 cleanWhitelist 保护的目录内。不接受任意路径删除。

清理应用临时文件

# 1) 试运行：列出可清理数量与体积（不删除）
curl -X POST http://127.0.0.1:19861/api/command \
  -H "Content-Type: application/json" \
  -d '{"cmd":"CleanAppTemp","dryRun":true}'

# 2) 确认后真正删除（默认移入回收站，可恢复）
curl -X POST http://127.0.0.1:19861/api/command \
  -H "Content-Type: application/json" \
  -d '{"cmd":"CleanAppTemp","dryRun":false,"useRecycleBin":true}'

CleanAppTemp 只扫描应用 temp/ 目录（条码 PNG、ESC/POS dump、Office/OFD 转换中间件等自产文件），阈值 minSizeMB 可为 0（不限大小）。与 CleanDisk 的区别：后者扫系统 Temp + 应用目录且默认最小 1MB，前者专注应用自产小文件、阈值可为 0。另可在「磁盘清理」页点「清理应用临时文件」一键操作，启动时还会按 tempAutoCleanMaxAgeDays（默认 7 天，0=关闭）自动清理过期文件。

状态查询

curl http://127.0.0.1:19861/api/status

返回示例字段：app、appCn、version、framework、websocket、webDocs、language/languageConfigured/languageDetected、aoEnabled/aoOnline/aoRelayUrl/aoDeviceId、defaultPrinter、supportedTypes、queue、uptimeSeconds。
