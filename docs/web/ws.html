ASP.NET Core 原生 WebSocket · 端口 19861

WebSocket 协议

连接 ws://<host>:19861/ws，发送一个 JSON 对象，cmd 指定命令，其余字段为该命令参数。服务端同步返回一条 JSON 响应。

WebSocket 与 Web 文档服务共用同一个 Kestrel 端口（19861），路径固定为 /ws， 由 ASP.NET Core 原生 WebSocket 实现接管（已移除第三方 Fleck 依赖，支持自动 TLS）。 连接建立后服务端会主动推送一条 operator: "startPrint" 的欢迎消息。之后每当打印队列变化，会向所有连接推送 operator: "QueueChanged" 快照。

服务健康检查

curl http://127.0.0.1:19861/health

返回 status、app、version、uptimeSeconds、web、ws、wsConnections、aoOnline、queue，可用于负载均衡与存活探针。

响应结构（所有命令统一）

{
  "code": 200,                    // 200 成功 / 400 参数错误 / 403 命令禁止 / 404 未实现 / 500 异常
  "timestamp": "1763019000",     // Unix 秒
  "data": { ... },               // 命令返回数据
  "error": "success",            // 失败时为错误信息
  "operator": "PrintFile",       // 回显命令名
  "uuid": "9f3c...",             // 本次响应唯一 ID
}

code 非 200 时请读 error；data 可能为 null。

命令清单

cmd作用主要参数
PrintPdf原有 PDF 打印命令（兼容保留）label、printer、copies、fit、scale、paperKind、printPages
PrintFile同步打印任意受支持文件 / URLpath（也可用 label/url）、printer、copies …
PrintBarcode生成条码/二维码并直接打印（SumatraPDF 直出）value（必填）、format（qr/code128/code39/code93/ean13/ean8/upca/itf/codabar/msi/pdf417/datamatrix/aztec）、width/height（px，默认 400）、caption（可选文字）、printer、copies、paperKind
纸张参数 paperKind：支持 A0–A5、letter/legal/tabloid/statement、auto（按页面尺寸）、"210mm x 297mm" 自定义尺寸或驱动报告名。其中 A0/A1 自动换算为 ISO 216 毫米尺寸（841×1189 / 594×841），大幅面实际输出需打印机驱动支持。
TemplatePrint模板渲染后入队打印template（文本或文件路径）、data（{{key}} 占位符）
PrintToPdf打印到 PDF 文件（Microsoft Print to PDF 虚拟打印机）path、output（输出路径，缺省落 temp/）、printer …
PrintToXps打印到 XPS 文件（图片/文本用内置写入器，其余回退虚拟打印机）path、output、printer …
PrintEscPosESC/POS 热敏小票原始打印（文本/一维码/二维码直发字节流）printer（本地名或 host:port TCP 9100）、text、encoding（默认 GB2312）、align、bold、barcode/barcodeFormat、qrcode、cashDrawer、feed、cut
QueuePrint加入打印队列，返回 jobId同 PrintFile；另支持 groupId/groupOrder（批次按序）、dueAt（到点才打印）、idempotencyKey（幂等防重，命中返回 deduped:true）
GetQueue查询全部任务与队列摘要—
RetryJob失败任务重试并前置id
CancelJob取消等待中的任务id
ClearQueue清空队列finishedOnly（默认 true）
SchedulePrint排一个计划任务，到点自动入队打印（持久化，重启不丢）dueAt（ISO8601 带时区 / Unix 秒 / 本地时间，必填）、job（PrintJob 对象）或平铺字段、idempotencyKey、note。返回 planId
ListSchedulePlans列出全部计划任务及摘要—
RemoveSchedulePlan撤回未触发的计划；now:true 则提前触发planId、now（默认 false）
PrintBatch批量/波次打印：整批同组按序入队，复用幂等与断网补打jobs（PrintJob 数组，必填）、groupId、idempotencyKey（前缀，按序加 :index）、dueAt。返回 groupId/jobIds/deduped
RecallJob召回撤回未开始打印的任务并记审计；printing 不可撤回id（jobId）、reason
RecommendPlan智能推荐错峰时段：基于近 14 天真实打印审计流水，无历史则按默认策略count（1-200）、printer（可选过滤 host）、withinHours（1-72，默认 8）、startAt。返回 basedOn（history/default）与 slots
GetPrinterList打印机名数组 + 默认 + 详情—
GetPrinterDetail仅返回详情数组—
SetDefaultPrinter切换系统默认打印机printer
PrintTestPage打印测试页printer（可空，用当前默认）
GetPdfDriverConfig读取 SumatraPDF 配置—
SetPdfPrintDriverConfig写入 SumatraPDF 配置config
ScanDisk扫描可清理文件maxAgeDays、minSizeMB
CleanDisk清理文件（默认 dryRun）paths、dryRun、useRecycleBin
CleanAppTemp清理应用自产临时文件（temp/ 目录，条码 PNG / ESC/POS dump / 转换中间件等）maxAgeDays（默认 0=不限）、minSizeMB（默认 0=不限大小）、dryRun（默认 true）、useRecycleBin。先 dryRun 拿数量，再 dryRun:false 真正删除（默认走回收站）
GetDiskInfo磁盘容量概览—
GetSettings读取当前配置—
SaveSettings部分更新配置任意配置字段
GetStatus运行时状态、版本、支持类型、队列摘要—
GetMachineFingerprint本机指纹（MachineGuid + 卷序列号 + OS + 用户 SHA1）—
CheckUpdate拉取 Gitee latest.json 对比版本（不下载）—
ApplyUpdate下载、校验 SHA256、替换当前目录—

完整实时清单：GET /api/commands。只有在 config/appsettings.json 的 allowedCommands 中的命令才可被网络调用。

示例：打印一个 PDF

// 发送
{"cmd":"PrintPdf","label":"https://example.com/label.pdf","printer":"HP LaserJet","copies":2,"fit":"fit","scale":"portrait","printPages":"1-"}

// 响应
{"code":200,"timestamp":"1763019000","data":{"label":"...","printer":"HP LaserJet","engine":"SumatraPDF","message":"已提交到打印机 HP LaserJet"},"error":"print successful!","operator":"Print","uuid":"..."}

兼容旧客户端：若 label 以 // 开头会自动补 https:；无协议但形似域名也会补 https://。本地绝对路径不会被误判为 URL。

示例：加入队列并轮询

// 1) 入队
{"cmd":"QueuePrint","path":"C:\\labels\\a.docx","printer":"HP LaserJet","copies":1}
// → {"code":200,"data":{"jobId":"3f9a...","job":{...,"status":"pending"}}, ...}

// 2) 查询
{"cmd":"GetQueue"}
// → {"code":200,"data":{"jobs":[...],"summary":{"total":1,"pending":0,"printing":0,"done":1,"failed":0}}, ...}

// 3) 失败重试
{"cmd":"RetryJob","id":"3f9a..."}

示例：模板打印

{"cmd":"TemplatePrint",
 "template":"<h1>订单 {{orderNo}}</h1><p>收件人：{{name}}</p>",
 "data":{"orderNo":"SO-20261113-001","name":"张三"},
 "printer":"HP LaserJet"}

含 HTML 标签时渲染为 .html 走无头浏览器转 PDF，否则渲染为 .txt。

浏览器端示例

const ws = new WebSocket('ws://127.0.0.1:19861/ws');
ws.onopen = () => ws.send(JSON.stringify({ cmd: 'GetStatus' }));
ws.onmessage = e => {
  const r = JSON.parse(e.data);
  if (r.operator === 'QueueChanged') console.log('队列变化', r.data.summary);
  else console.log('响应', r);
};

Active-Online Print（AO 主动在线打印）

本终端可主动向 AoRelay 中继服务器 建立出站长连接，由网页 / 中台经中继下发打印任务，实现广域网远程打印。在「设置 → 主动在线打印（AO）」中启用并填写中继地址即可，启用状态变更立即生效，无需重启。

终端侧（自动）
  ws://<host>:<port>/device   终端出站长连接：hello 注册（设备名/打印机列表）、30s 心跳、接收 job、回传 result

中继侧（AoRelay）
  ws://<host>:<port>/client   业务方连接：list 设备、job 下发任务、接收 result
  GET /api/devices               在线设备列表（JSON）
  GET /ao.html                   浏览器测试页
  GET /health                    健康检查
配置项默认说明
aoEnabledfalse启用后本终端主动连接中继，接受远程任务
aoRelayUrlws://127.0.0.1:8081中继地址，支持 ws/wss/http(s)，自动换算 ws
aoKey""共享密钥，留空则不校验
aoDeviceName机器名中继内唯一设备 ID（仅字母/数字/-/_/./@）

任务经 CommandDispatcher 白名单执行，只有已配置的命令可被远程调用；断线后指数退避自动重连（1s→2s→4s→…→30s 封顶）。

磁盘清理默认安全： CleanDisk 未显式传 "dryRun": false 时只做试运行不删除； 且只能删除应用临时目录与系统 Temp 下、不在白名单里的文件。请先用 ScanDisk 拿到路径再提交。
